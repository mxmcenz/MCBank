# MCBank

Учебный проект банковского приложения, разработанный для практики и понимания внутренней логики работы банковских систем (управление счетами, транзакции, депозиты).

## Основной функционал
- Управление банковскими счетами
- Проведение транзакций и переводов
- Работа с депозитами

## Технологический стек
* C# / .NET, JWT
* База данных PostgreSQL
* ORM Entity Framework Core
* JS, Vue
